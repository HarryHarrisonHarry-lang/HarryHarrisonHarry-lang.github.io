Privacy Policy

Last updated: September 28, 2026

What Harry OS is

Harry OS is a personal dashboard used by a single person, its owner. It runs only on the owner's own computer and is not offered to the public.

What data it accesses

With the owner's permission, Harry OS reads the owner's Gmail messages and Google Calendar events using read-only access. It cannot send, change or delete email or calendar events.

How data is used and stored

  • Data is used only to display the owner's own calendar, inbox and tasks to the owner.
  • Data is stored only on the owner's computer. It is not uploaded to any server, sold or shared with anyone.
  • Google user data is not used for advertising and is not transferred to third parties.

Harry OS's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from Google Account permissions. Deleting the app's local data folder removes all stored data.
